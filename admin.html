内推岗位管理

本页完全在你本地运行，不上传任何第三方服务器；岗位直接写入 GitHub 仓库的 jobs.json。保存后所有已生成的二维码约 30 秒自动更新（页面每次打开实时拉取）。

⚠️ 检测到你是用 file:// 直接双击打开本页。这种打开方式浏览器会用“空源”请求 GitHub API，被 CORS 拦截，必然报 Failed to fetch。
请改用 http 方式打开：在本文件夹运行 python -m http.server 8000，然后浏览器访问 http://localhost:8000/admin.html；或在 WorkBuddy 里用预览/http 方式打开本文件。

操作建议：Token 在 github.com → Settings → Developer settings → Personal access tokens → Tokens (classic) 生成，勾 repo，期限选 7 天即可。保存完成后请回到该页面将其 Revoke 删除。
